# KADEN Concierge

日立の家電品のSNS運用を支援する、ローカル保存型の業務アプリです。日立・Anthropicの公式サービスではありません。

React / Vite、Node.js 24、Express、SQLite、Anthropic Messages API、Google OAuth、python-pptxで構成しています。

## 起動

公開URLを発行する場合は [Render公開手順](DEPLOY_RENDER.md) と `render.yaml` を使用してください。HTTPS・パスワード認証・永続ディスクを用意する構成です。Renderアカウントと有料構成への同意が必要です。

クラウド環境では `/workspace/-` を使用します。既存のチェックアウトを使い、Git worktreeを作る必要はありません。

```bash
cd /workspace/-
bash scripts/setup.sh
npm start
```

標準ポートは3000、待ち受けは `127.0.0.1`。`npm run dev` はAPI（3000）と開発画面（5173）を同時に起動します。設定ファイルを使う場合は `node --env-file=.env server/index.js` としてください。`.env`は自動読込しません。

必要条件：Node.js 24以上、Python 3.12以上、LibreOffice（`soffice`）。セットアップはPythonの仮想環境 `.venv` に `requirements.lock`、Nodeに `package-lock.json` を使用して依存を導入し、画面をビルドします。このクラウド環境ではLibreOfficeを確認済みです。他のマシンでは事前に導入してください。

## 最初の設定

1. 「連携・設定」でAnthropic APIキーを登録。ClaudeのWeb版契約とは別のAPI利用設定が必要です。値をチャットやGitに貼り付けないでください。
2. Google Cloudで **Calendar API / Sheets API / Drive API** を有効化。OAuth同意画面と「ウェブアプリケーション」クライアントを作成。テスト中は使用アカウントをテストユーザーに登録します。
3. リダイレクトURIに `http://127.0.0.1:3000/api/google/callback` を登録し、アプリに同じURIとクライアントID・シークレットを保存。「Googleを接続する」で認証します。開発画面から認証してもコールバックはAPI側です。
4. 対象カレンダーID、スプレッドシートID、専用タブ名を指定。接続アカウントには書込み対象の編集権限、Driveフォルダの閲覧権限が必要です。
5. 「Drive・資料ワークフロー」→「Driveから選ぶ」で共有フォルダから資料を取り込みます。サブフォルダ・ページ送りに対応。元のDriveファイルは変更しません。

Drive初期フォルダは「連携・設定」で共有フォルダのIDまたはURLを任意登録できます。未設定の場合は「Driveから選ぶ」で入力してください。Claudeプロジェクトへの参照リンクも「連携・設定」で任意登録できます。PPTX・XLSXを直接アップロードすることもできます。Googleスライド・シートはOffice形式にエクスポートして取り込みます。

重点指標は **Imp、ENG、再生数**。`engagements` は公式集計のENG、いいね・コメント・保存・共有の和は「観測反応数」として分けます。未取得項目は `null` を保持し、0件の実測と区別します。反応率は取得済みの分母（リーチ→表示回数→フォロワー）を明記し、同一SNS・同一分母・同一反応項目の投稿間で比較する指示を送ります。

## Skills

今回のチャットで共有された2件の**スキル説明全文**を初期登録しています。Claudeプロジェクト内部のSKILL.md・添付ファイル・過去チャットはURLから取得していません。

「Skills・指示の管理」で、完全な指示やブランドルールを貼り付け、または `.md` / `.txt` から登録できます。有効な指示は全文を毎回送信し、SHA256と使用モデルを生成結果に保存します。合計180KBを超えた場合は切り捨てず停止します。モデルの厳密な遵守・ブランド適合は人による確認が必要です。

## CSVとスプレッドシート

「競合・トレンド分析」から空のCSVテンプレートをダウンロードできます。

```csv
date,platform,accountType,account,url,content,impressions,reach,engagements,likes,comments,saves,shares,views,followers
```

- `date`: `YYYY-MM-DD`、`platform`: `Instagram` / `X`、`accountType`: `competitor` / `own`（日立実績）
- 未取得指標は空欄、取得済みの0は `0`。投稿URLを使い重複取込を防ぎます。更新した値を取り込む場合は古い投稿データを削除して再取込してください。既存の分析結果は過去のスナップショットとして保持します。
- スプレッドシートへの追記は専用タブを使用します。列順は `実行ID / 期間開始 / 期間終了 / 企画タイトル / SNS / 商品カテゴリ / 導入表現 / 企画構成 / 根拠URL / 表現上の確認事項`。空のタブには初回に見出しを追加。既存列が異なる場合は変更せず停止します。規定シートの列が違う場合は、その実物を確認したうえで列マッピングの追加が必要です。
- 値はSheetsの `RAW` で送信。実行IDで重複追記を確認します。CSVは数式として評価される値をエスケープします。

## 定期実行

初期値は **木曜日12:00 / Asia/Tokyo**。有効化は「連携・設定」から行います。AI料金と外部書込みをユーザーが設定するまで、初期状態はOFFです。

- 日別：前日分の競合データ。
- 週次：指定曜日に前日までの7日間。必要に応じ週次資料も生成。
- 月次：毎月1日に前月分の資料。
- 「週次企画案を指定シートにも自動追記」をONにした場合のみ、週次結果を確認操作なしで外部へ追記。
- 同じ日・種別の処理は重複実行しません。失敗・実行中・完了は「AIワークフロー」の履歴で確認できます。失敗分は原因を修正後、手動実行してください。
- **サーバー稼働中のみ**実行します。過去の停止期間の遡及実行、停止中に中断したジョブの自動再実行はありません。継続運用には常時稼働のホスティングとプロセス管理が必要です。

## 保存・連携

- `.data/`（または `DATA_DIR`）にSQLite・ローカル暗号鍵・アップロード資料・出力を保存します。APIキーとOAuthトークンはAES-256-GCMで暗号化し、APIで値を返しません。バックアップは**鍵とデータを一緒に**保全してください。
- 単一チーム向けのローカル版です。外部へバインドする場合は `APP_PASSWORD` が必須。TLSとアクセス制御を行うリバースプロキシを用意し、`HOST`、`APP_ORIGIN`、OAuthリダイレクトURIを設定してください。ユーザー別権限・監査用の本人識別・複数サーバーでの並行運用は未実装です。
- サンプルデータには常に表示を付け、外部へのカレンダー登録・シート追記を拒否。サンプル削除は実データに影響しません。
- カレンダーはタスクIDに由来する安定したイベントIDで更新。タスクを編集後は「再反映」を実行。タスク削除はカレンダーイベントを自動削除しません。
- 必要な送信先：`api.anthropic.com`、`www.googleapis.com`、`sheets.googleapis.com`、`oauth2.googleapis.com`。ブラウザー認証には `accounts.google.com`。Google/Claudeの認証値はアプリ設定または環境変数を使用します。

## 現時点の制約

- Instagram / Xの自動取得・自動投稿は未接続。提供されたCSVや手動入力を使います。URLだけの参考投稿は本文を取得した扱いにせず、本文も入力します。
- 指定されたSpreadsheets / Presentationsプラグインはこの実行環境で利用できないため、Google APIとCSV・PowerPoint出力で実装しています。
- 実際の共有Drive資料は未取得。OAuth認証後、アプリ内で選択してください。Google連携とClaudeの本番呼出しは、認証情報未設定のため未検証です。
- PPT画像化はLibreOffice経由。画像内の文字・複雑な表セルの書換え、曖昧な矢印の対象判断、図形の一部だけの削除には自動対応しません。未解決を完了扱いにせず、部分反映として出力できます。原本は残ります。
- X審査PPTは、タイトル・本文・リプライ・訴求・画像ラフの**別々のテキストボックス**を選択する方式。画像ラフは編集可能なテキスト構図で、生成写真ではありません。元資料を保持し末尾に企画ページを追加します。
- 定例資料は標準のPowerPointレイアウト。過去資料を構成の参考にできますが、そのままのテンプレート再現ではありません。
- ファイルは25MB以下、PPTXは80スライド以下、Excelは合計1万行以下・100列以内。抽出データが上限を超えた場合は省略せずエラーにします。

## 検証

```bash
npm test
npm run build
npm run test:browser
npm audit --omit=dev --audit-level=high --cache /tmp/hitachi-npm-cache
```

APIテストは一時SQLiteで保存、引用整合性、未知の指標、重複、木曜12時の定期実行、CSV、PPT本文置換・注釈削除、書式保持、X審査PPT複製を確認します。AI応答はモックであり、実際のモデルの読解精度やGoogle API権限を検証したものではありません。

ブラウザーテストは `/usr/bin/chromium` を使用し、投稿・タスク保存、再読込、ドラッグ、CSV、Skills、ワークフロー、Google未接続エラー、Office取込、PPTXダウンロード、設定、モバイル幅を確認。`test-results/` にサンプル入りの画面画像とPPTXを生成します。
